This is a project for my school aimed at creating the best solitaire experience inside your terminal.
A Linux version shall be made soon.

Play the latest Windows version of Terminal Solitaire here.
[Releases page](../../releases/latest).

Controls:

m - to select a card , then m again to move it
d - draw a card from the pile

Card Colors:

Black - Spades
Grey - Clubs
Red - Hearts
Purple - Diamonds
